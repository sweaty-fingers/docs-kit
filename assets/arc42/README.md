# 아키텍처 (arc42)

이 프로젝트의 **정본** 아키텍처 문서입니다. arc42의 12개 섹션으로 나눠, 무엇을 왜 이렇게 만드는지를 섹션마다 한 곳에 둡니다. 섹션은 필요할 때 채우고, 각 섹션의 상태(비어 있음 · 일부 · 안정 · 해당 없음)를 아래 표에서 봅니다. 표의 **담는 것**은 그 섹션에 들어가야 할 내용([문서 규격](../docs-standard.md) §3 요약), **지금 들어 있는 것**은 각 섹션 머리말의 `summary`입니다. 담지 않는 것까지 자세히는 문서 규격 §3에 있습니다.
