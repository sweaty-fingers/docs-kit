# 검증 기록 템플릿

새 검증 기록(VR)은 아래 블록을 복사해 `docs/records/NNNN-짧은-영문-제목.md`로 저장하고 채웁니다. 증거 파일은 `docs/records/assets/VR-NNNN/`에 둡니다. **재현 스크립트(`repro.sh`)와 기대값(`expected.txt`)도 같은 폴더에 함께 만듭니다**([목록](README.md) §2). 규칙은 [목록](README.md) §2를 봅니다. `< >` 안은 바꿀 자리이고, 쓸 내용이 없는 선택 칸(`(선택)`)은 줄째 지웁니다.

````markdown
---
result: pass                # pass | partial | fail
date: 2026-11-05            # 실행한 날 (YYYY-MM-DD)
by: [<이름>]                # 실행한 사람
area: dev-env               # ADR과 같은 분야 (docs-kit.yml areas)
subject: <목록에 들어갈 한 줄: 무엇을 확인했나>
host: <실행한 곳 (예: 개발 PC, 서버 이름, GPU)>
commit: <저장소 커밋 (git rev-parse --short HEAD)>
adr: [<이 기록이 근거가 되는 ADR 번호>]
guide: <따라 한 절차 (예: G1 §3~§5)>
c4: [<요소 id>]             # (선택) docs/adr/c4-model.yml의 요소 id
# supersedes: 1             # (선택) 같은 대상을 다시 검증해 이 기록이 대신하는 VR 번호
---
````
