# 스프린트

일을 짧은 주기(스프린트)로 나눠 계획하고, 끝나면 무엇을 약속했고 무엇을 끝냈는지, 무엇을 다음으로 넘겼는지, 무엇을 배웠는지(회고)를 남깁니다. 카드는 [현황판](README.md#단계별-진행)의 Backlog와 WBS이고, 상태의 근거는 그대로 로드맵과 이슈입니다. 보드에서 카드를 끌어 옮기면 `docs/plan/sprints.json`에 기록됩니다(고치는 법: [현황판 편집 안내](guide.md#5-스프린트-보드-sprintsjson)).

| 칸 | 뜻 |
| --- | --- |
| 백로그 | 아직 스프린트에 넣지 않은 일 |
| 할 일 | 이번 스프린트에 하기로 한 일 |
| 진행 중 | 손대고 있는 일. 한 번에 너무 많이 벌이지 않도록 한도(WIP)를 둡니다 |
| 검토 | 손으로 할 일은 끝났고 확인을 기다리는 일: ADR 승인, MR 병합, 사람이 직접 하는 실행·확인, VR 재현 |
| 완료 | 끝난 일. 근거(로드맵 done, 이슈 닫힘)가 없으면 "근거 필요"로 표시합니다 |
