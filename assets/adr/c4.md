# 아키텍처 (C4)

과제의 구조를 **C4 모델**(Context → Container → Component → Code)로 보여 주고, 각 결정(ADR)이 어느 요소에 걸려 있는지 함께 보여 주는 페이지입니다. 그림은 `docs/adr/c4-model.yml`과 ADR 머리말의 `c4:`에서 자동으로 만들어집니다. 고치는 법은 [작성 가이드 §9](guide.md#9-아키텍처-c4-모델-관리)를 봅니다.

**아키텍처 뷰어**는 화면 전체를 쓰는 별도 페이지입니다. 그림 탭(Level 1 컨텍스트, Level 2 컨테이너)과 **결정 카드** 탭이 있고, 다음처럼 씁니다.

| 동작 | 결과 |
| --- | --- |
| 카드 클릭 | 오른쪽 패널에 설명, 기술, 관련 결정 카드, 보내는/받는 관계 |
| 카드 더블클릭 또는 "→ 안으로 들어가기" | 그 시스템의 컨테이너 그림으로 이동 |
| 카드·관계 라벨에 마우스 | 연결된 요소와 관계만 강조 |
| 결정 필터 | 고른 ADR이 걸린 요소만 강조, 패널에 결정 카드 |
| 휠 / 끌기 / 오른쪽 아래 버튼 | 확대·축소 / 이동 / 확대·축소·화면에 맞춤 |
| 위쪽 반달 버튼 | 밝은/어두운 테마 (선택은 브라우저에 기억) |
| 주소 복사 | `#view=…&el=…`, `#tab=decisions`로 같은 화면 공유. ADR 카드와 의사결정 로그의 요소 링크도 이 주소로 열림 |
