# 의사결정 로그

지금까지의 결정을 **시간 순서로 한 줄씩** 모은 페이지입니다. 개별 ADR을 열지 않고도 무엇을 언제 정했는지 훑어볼 수 있습니다. 상태·분야별로 보려면 [ADR 목록](README.md), 결정이 시스템의 어디에 걸려 있는지 보려면 [아키텍처 (C4)](c4.md)를 봅니다.

아래 표는 각 ADR 머리말의 `date`, `summary`, `status`, `c4`에서 자동으로 만들어집니다(날짜 순, 같은 날은 번호 순). 직접 고치지 않습니다. GitLab 화면에서는 표가 비어 보이므로 문서 사이트(`.docs-kit/bin/docs.sh`)에서 봅니다.
