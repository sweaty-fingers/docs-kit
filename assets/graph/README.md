# 문서 지도

모든 문서를 밤하늘의 별로, 서로 관련된 문서를 빛줄기로 이어 한 장의 지도로 봅니다. 색은 문서 종류이고(목록은 빈 고리, 종류는 마우스를 올리거나 누르면 글로도 나옴), 별이 클수록 연결이 많은 문서입니다.

- **선의 종류**: 본문 링크(가는 회색), 머리말 관계(굵은 선: VR이 검증한 결정, 관련 결정, 대체, 발행물의 근거 섹션), 비슷한 내용(점선: 아직 링크는 없지만 낱말·가리키는 문서·C4 구성요소가 겹치는 문서).
- **문서를 누르면** 옆 패널에 요약, 링크하는 문서와 링크받는 문서, 머리말 관계, 비슷한 문서와 **왜 비슷한지**가 나옵니다. "주변만"을 켜면 그 문서에서 1~3단계까지만 봅니다.
- 아무것도 고르지 않았을 때 패널의 **점검**에는 연결이 없는 문서와 링크를 걸면 좋을 문서 쌍이 나옵니다. 맞으면 본문에 링크를 넣으면 됩니다.
- **주제별로 모입니다.** 주제는 로드맵 트랙(`docs/roadmap/roadmap.yml`의 `tracks`)과 공통입니다. 로드맵을 쓰지 않으면 주제 없이 링크로만 모입니다. 주제마다 같은 색의 성운이 깔리고, 서로 링크가 많은 주제끼리 이웃합니다. 주제가 둘인 문서는 두 성운 사이에 놓입니다. 위쪽에서 "모으기: 링크만 / 종류", "색: 종류 / 분야"로 바꿀 수 있습니다.
- 지도는 빌드할 때 문서에서 자동으로 만들어집니다. 주제를 바로잡을 때만 머리말 `topics`나 `docs/graph/topics.yml`을 고칩니다(아래 "주제를 정하는 순서").

## 연결을 판단하는 방법

| 선 | 근거 | 세기 |
| --- | --- | --- |
| 본문 링크 | 렌더된 본문의 링크 (자동 링크된 "배경 01 §4" 같은 참조 포함). 방향이 있어 "링크받는 문서(백링크)"도 봅니다 | 실제 연결 |
| 머리말 관계 | VR `adr`(검증), ADR `related`(관련 결정)·`supersedes`(대체), 실험 `adr`, 발행물 `based_on`(근거), VR `guide` | 사람이 선언한 연결이라 가장 강함 |
| 비슷한 내용 | 0.55 x 본문 낱말 유사도(TF-IDF, 조사 제거) + 0.30 x 같은 문서를 가리키는 정도(서지 결합) + 0.15 x 같은 C4 구성요소. 문서마다 상위 3개, 아직 링크가 없는 쌍만 | 제안: 이유를 보고 맞으면 링크로 |

## 주제를 정하는 순서

| 순서 | 어디서 | 예 |
| --- | --- | --- |
| 1 | 머리말 `topics` (최대 2개, 첫째가 주 주제) | `topics: [core, ui]` |
| 2 | `docs/graph/topics.yml`: 쓴 뒤 고치지 않는 ADR·VR이나 확인한 추정 | `ADR-0003: [core]`, `G2: [core, ui]` |
| 3 | 로드맵 항목의 `refs` (자동) | VR-0004가 트랙 core의 로드맵 항목 refs에 있으면 core |
| 4 | 이웃 문서(링크·관계·비슷한 문서)에서 추정 (자동, "추정" 표시) | 이웃이 고르게 나뉘면 공통 |

주제 이름은 로드맵 트랙 id(예: `env`, `core`, `ui`)와 `common`입니다. 없는 이름을 쓰면 빌드 경고가 납니다.

흔한 문서(목록, 사용법)를 많이 가리키는 것보다 드문 문서를 함께 가리키는 것이 더 큰 점수를 받습니다. 목록·안내 문서는 모든 문서와 이어져 지도를 가리므로 처음에는 숨겨 둡니다(위쪽에서 켤 수 있음).
