# 용어집

이 프로젝트 문서에 나오는 용어를 **한곳에서** 찾는 색인입니다. 한 줄 뜻과 자세한 설명이 있는 위치를 적습니다. 자세한 설명은 그 용어를 가장 잘 다루는 문서 한 곳에만 두고, 다른 문서에 용어 표를 만들지 않습니다.

| 용어 | 한 줄 뜻 | 자세히 |
| --- | --- | --- |
| ADR | 아키텍처·기술 결정 기록 (결정 하나에 문서 하나) | [ADR 목록](../adr/README.md) |
| 정본 | 사실과 결정을 두는 유일한 문서 (arc42, ADR, EXP, VR, MC) | [문서 규격](../docs-standard.md) §1 |
